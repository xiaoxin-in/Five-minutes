# 5分钟（Five Minutes）

一个帮你把「想做但一直没开始」的事，压缩到 5 分钟内启动的**反拖延 Agent**。

> 拖延症患者真正的问题不是不会管理时间，而是**启动门槛太高**。
> 番茄钟的 25 分钟对他们只是二次伤害——我们只需要 5 分钟：
> 小到不好意思拒绝，大到足以完成"开始"这个动作。

## 它能做什么

| 功能 | 说明 |
|---|---|
| 💬 对话式入口 | 一句话自然语言（"我打算今晚八点跑步"），Agent 负责结构化，绝不让用户填表单 |
| 🚀 2 分钟启动器 | 把模糊任务拆到"小到不好意思拒绝"："写论文" → "打开文档写一句标题" |
| ⏰ 承诺追问闭环 | 说过今晚 8 点跑步，到点必追问，直到给出答复；追问**硬上限 2 次**，放弃则温和收尾 + 次日提前提醒 |
| 🧺 琐事批处理 | 5 分钟琐事清单攒批，合适时机推送"正好有空，干掉这 3 件？" |
| 🌱 微小胜利记录 | 自动记录每天完成的事，对抗"我这周啥也没干"的认知偏差 |
| 🔍 时间照妖镜 | 甩历史数据："上次你说 1 小时，实际 2.6 小时" |

**产品语气铁律：队友，不是监工。** 情绪优先（先接住"我又废了"，再给 5 分钟重启动作），稍有说教感用户就会关掉通知。

## 快速开始

```bash
npm install
npm run dev     # → http://127.0.0.1:8787
npm test        # 14 项测试
```

依赖：Node.js ≥ 22.5（使用内置 `node:sqlite`，无需任何原生编译）。

体验追问闭环：对话页输入「我打算今晚八点跑步」→ 点顶部「演示：立即触发追问」→ 会出现「开始了 / 再拖10分钟 / 今天算了」三个选项，不同选择走不同分支。

## 技术架构

```
Vue 三页(免构建静态) ──REST──▶ Fastify API ──▶ SQLite(node:sqlite)
                                   │
                    ┌──────────────┼──────────────┐
                Agent 服务      调度器(15s轮询)   规则引擎/LLM适配
             （拆任务/降门槛改写） （扫描到期承诺）  （LLM 未配 key 时降级）
```

- **后端**：TypeScript + Fastify，单进程单仓库
- **数据库**：SQLite（Node 22 内置），4 张核心表：`tasks` / `commitments` / `messages` / `victories`
- **追问状态机**（产品核心）：`pending → asked → started | snoozed → given_up`，纯函数实现、表格驱动测试
- **调度器**：15s 轮询到期承诺触发追问，接口已抽象，将来可无痛换 BullMQ

```
server/src/
├── db.ts            # 建表与类型
├── repo.ts          # 数据访问层
├── stateMachine.ts  # 承诺追问状态机（核心，纯函数）
├── scheduler.ts     # 到期扫描与追问触发
├── seed.ts          # 首次启动种子数据
├── api.ts           # Fastify 路由
└── agent/
    ├── agent.ts     # 规则引擎 Agent + LLM 适配器接口
    └── prompts.ts   # 提示词资产（版本化管理）
server/test/         # 14 项测试（状态机/时间解析/API 集成）
web/index.html       # 三页前端（免构建，直接由 Fastify 托管）
demo/index.html      # 最早的纯前端交互 Demo（保留作参考）
docs/                # 产品设计文档 / 技术方案
```
